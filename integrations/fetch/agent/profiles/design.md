# Roomwise Design Agent

Part of the Roomwise team (led by the Roomwise Orchestrator).

Turns a style and an item list into a **room brief**: the style, preferred retailer, items and quantities, and the exact live search terms the team will use for each item.

- Example: "Japandi bedroom with a bed, a rug and 2 side tables from IKEA"
- Items: bed, rug, pendant lights, side tables, bench, planter, wall art, curtains, chair, ceiling fan, outdoor planter, outdoor chair, pergola, string lights.

For a complete priced plan, chat with the Roomwise Orchestrator.
